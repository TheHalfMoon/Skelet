## Fix applied in this grain

Root `package.json` gains a pnpm override pinning `postcss` to `8.5.30`
(exact, reproducible). Rationale: postcss 8.5.x is API-compatible with 8.4.x
(same major); Next 15.5.27 accepts it via its `^8` range; the override closes
all four postcss advisories at once. Verified by:

- `pnpm install` regenerates the lockfile with a single `postcss@8.5.30`.
- `pnpm audit --json` afterwards reports zero postcss advisories.
- `pnpm --dir apps/web build` passes (production build green).
- Exact-head CI re-verifies the frozen lockfile install plus build.
